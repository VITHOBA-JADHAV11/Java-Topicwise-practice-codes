# Java Complete Topic-wise Practice Repository

This repository is organized by **topics → subtopics → programs**.

Each Java file includes:
- Problem title and practice objective
- Runnable Java code
- Interview revision comments
- Complexity-analysis guidance
- Edge-case practice guidance

## How to run
```bash
cd 01_Basics/Conditionals
javac EvenOdd.java
java EvenOdd
```

## Recommended learning order
1. Basics
2. OOP
3. Arrays & Strings
4. Collections
5. Exception & File Handling
6. Java 8 Features
7. Multithreading
8. DSA

## Difficulty method
Within every subtopic, first understand the simple program, then modify it for:
- user input
- invalid input
- reusable methods
- better time complexity
- test cases
- interview-style variations

Note: The programs are runnable practice implementations. Use the comments and README to expand each one into interview-level variations.
